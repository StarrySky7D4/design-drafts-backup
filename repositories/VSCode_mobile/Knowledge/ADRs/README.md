# Architecture Decision Records

状态：M0-08已建立流程；当前已批准ADR如下。

- [ADR-0001：作者自用与仅源码公开交付定位](0001-source-only-distribution.md)

架构、安全、协议兼容、持久化、运行时隔离或不可逆生成/发布决策必须从`templates/ADR.md`创建编号文件`NNNN-short-title.md`。状态只允许`Proposed`、`Accepted`、`Superseded`、`Rejected`；只有具有真实评审证据的记录可改为`Accepted`。聊天、任务记录和临时说明不能替代ADR。

每份ADR至少含“状态、背景、决策、后果、回滚”，并链接受影响的ROADMAP、DEFECTS和协议/结构登记。ADR-0001来自用户明确冻结的交付定位；后续状态变化仍须真实评审证据。
